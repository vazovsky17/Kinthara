# Contributing to Kinthara

Thank you for your interest in Kinthara.

Kinthara is a personal software engineering and game development portfolio project created and maintained by Vazovsky.

## Project Policy

Kinthara is a **source-available, proprietary project**.

The repository is public to demonstrate its architecture, implementation, development process, and technical decisions.

It is not an open-source project.

All rights are reserved by the copyright holder.

## Contributions

External code contributions are not currently accepted.

Please do not submit pull requests containing code changes, new features, refactoring, or other implementation work without prior written agreement from the project owner.

Unsolicited pull requests may be closed without review or integration.

## Issues and Feedback

Constructive feedback, bug reports, and technical discussions are welcome through GitHub Issues, if enabled.

Please avoid submitting confidential information, proprietary code, or third-party copyrighted materials.

Submitting feedback does not grant permission to use, reproduce, modify, or redistribute Kinthara's source code.
